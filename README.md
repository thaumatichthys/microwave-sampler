# Travelling Wave Sampler
Based on a 1986 patent by Agoston Agoston from Tektronix. (Don't worry, it is expired by now trust)

This design removes the need for a very fast sample strobe (usually generated by a step-recovery diode, on the order of tens of picoseconds) for a possibly longer strobe, only requiring a fast falling edge.

During sampling, the strobe sends a symmetrical (+ and -) strobe pulse to the sampling bridge. The two diodes on the edges turn on first, and then a small delay later (due to the length of transmission line between them), the 
inner two diodes turn on. At this point the input signal will propagate through the bridge in common mode (on both sides in the same polarity) and be absorbed by the strobe generator circuit's 
output return loss.

On the falling edge of the sample strobe, the outer diodes turn off, causing the signal propagating through the bridge to be reflected back from that point. As the input signal's reflection 
reaches the inner two diodes, they also turn off, and then the signal wave is trapped between the inner and outer diodes. This wave eventually settles into a DC voltage that can be read out.

The output voltage is basically stored as a tiny charge on the microstrip line between the diodes. The differential voltage across the two sides of the bridge have a lot of random garbage on them,
so we add the two sides of the (hopefully symmetrically laid out) bridge, and they combine into a relatively clean common mode voltage. The charge is tiny though, so we dump them into op amp buffers
first. 

The op amp outputs then go into a high pass RC circuit. This might seem like shooting ourselves in the feet but it actually is required, more details later. This then goes into another buffer and then into a 
gated integrator circuit. Since the charge in the original sampling gate is so small, it is almost impossible to read it out accurately, and have it hold long enough to last several microseconds.
Thus, we integrate it's charge into a bigger capacitor. In essence this is another, slower, sample and hold. The switch gates an integrator, which samples the buffered 
bridge sample voltage early in its decay, to get a clean reading. This integrator output is then fed into a delay line (important later) and then amplified and buffered again and sent
off to the DC bias of the bridge. 

The DC bias of the bridge follows the integrator output (delayed), and this is so that between slow samples, the output voltage will actually converge towards its proper value, even if the gain of the 
sampler is not correct. However this gain should still be adjusted manually so that a single shot sample is correct on the first round. Back to the bridge bias. The diodes are biased through resistors, and then 
another resistor that goes directly across the outer diodes. This resistor basically creates a small negative bias after each sample strobe, because the AC coupling capacitor of the strobe generator will
accumulate some voltage during the strobe. Aside from that, you might have noticed that the bias resistor actually drains out the tiny sampling capacitance. This also creates another
problem because when the gated memory integrator is active, there is now a positive feedback path and the DC bias circuit will run away if not cared for.

The solution is to add a delay line (mentioned earlier) that delays the signal for approximately the time that the integrator is active, so the integrator's own output will not reach its input again until the next
sample. The slow RC constant of the bias resistor also helps this.
